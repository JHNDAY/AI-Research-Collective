Saving a web page into Claude

Save an HTML page from Safari, hand it to Claude, and get it back as an artifact: a private page inside Claude that you can view, export, share, and change just by asking.

Safari→.html file in Downloads→Claude chat→Artifact
Part one

Save the page from Safari

1

Open the page you want to keep

In Safari, go to the page. Here it is AI in Psychiatry on jhnday.github.io, but any web page works the same way.

Let the page finish loading before you save it.

2

Choose File › Save As

From the Safari menu bar choose File › Save As…, or press ⌘ S. A dialog drops down.

  • Save As: keep the name or type a shorter one.
  • Where: Downloads is easiest to find later.
  • Format: pick Page Source.

Click Save. You now have a file ending in .html in Downloads.

Why Page SourcePage Source saves the plain HTML text, which Claude can read. The other choice, Web Archive, is a Safari-only format.
Part two

Bring the file into Claude

3

Start a new chat

Go to claude.ai and start a new chat. Check that Chat is selected under the message box.

4

Click the + button

Click + at the lower left of the message box, then choose Upload or add files. The shortcut is ⌘ U.

5

Pick the file

A picker opens. You have two routes:

  • Your saved file: click Upload from computer, open Downloads, and choose the .html file from step 2.
  • A page already in Claude: tick it in the list, then click Add to chat (⌘ ↩).
Which one to useIf you tick an artifact from the list, Claude works from that artifact, not your saved file. To work from the file you just saved, use Upload from computer.
6

Tell Claude what you want

The file appears as a chip in the message box. Type your request after it and press send. This wording works well:

Create an HTML file artifact (not an inline widget) from the uploaded HTML file.

Saying “not an inline widget” asks for a full page you can keep, rather than a picture inside the chat.

Part three

View and edit the artifact

7

See it open beside the chat

Claude works for a moment, then the artifact opens in a panel on the right. In the chat, a card names it and says Artifact · Only you: it is private until you share it.

Along the top of the panel:

  • Export downloads a copy.
  • The speech bubble adds a comment.
  • The arrows open it full screen; the ✕ closes the panel.
8

Edit by asking

To change the page, stay in the same chat and say what you want in plain words. Claude updates the same artifact, so its link stays the same.

  • Make the headline smaller.
  • Add a short summary under the title.
  • Change the date to November 1, 2026.

To find it again later, click +, then Upload or add files; your artifacts are listed there, newest first.

Good to knowAn artifact can be reopened in a new chat. Tick it in the picker (step 5), add it to the chat, and ask for the change you want.
